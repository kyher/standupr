# Standupr

A team stand-up tool for sharing daily updates. Team members post notes to a shared standup board, grouped by person, with support for flagging blockers.

Built with Laravel 13, Vue 3, and Inertia.js.

## Stack

- **Backend:** PHP 8.3+, Laravel 13, PHPUnit 12
- **Frontend:** Vue 3.5, TypeScript (strict), Vite, Tailwind CSS v4
- **UI:** Shadcn-Vue (Reka UI), Lucide icons
- **Database:** SQLite (default)

## Getting Started

```bash
composer setup
composer dev
```

`composer setup` installs dependencies, copies `.env`, runs migrations, and builds frontend assets. `composer dev` starts the Laravel server, queue worker, log watcher, and Vite dev server concurrently.

## Commands

### Development
```bash
composer dev        # Start all dev servers
composer setup      # First-time setup
```

### Testing
```bash
composer test                                          # Full test suite (runs lint first)
./vendor/bin/phpunit tests/Feature/SomeTest.php        # Single file
./vendor/bin/phpunit --filter test_method_name         # Single test
```

### Linting & Type Checking
```bash
composer lint          # Fix PHP style (Pint)
npm run lint           # Fix TS/Vue style (ESLint)
npm run format         # Fix JS/Vue/CSS formatting (Prettier)
npm run types:check    # TypeScript type check
composer ci:check      # Full CI suite locally
```

## Architecture

Controllers return `Inertia::render()` responses. Vue pages in `resources/js/pages/` receive props directly — no separate API layer. Auth is handled by Laravel Fortify.

Route helpers are generated by Wayfinder (`resources/js/actions/`) and are type-safe. The `@/` path alias points to `resources/js/`.
